# 訊號終端 v1.1.0

投資 dashboard 的主站。網站放在 GitHub Pages，資料由 GitHub 雲端排程產生；NAS 負責備援與歷史資料；在自己的電腦上打開時，自動使用本機的 NPU、CPU 與語言模型。

| 角色 | 放在哪裡 | 做什麼 |
|---|---|---|
| 主站 | GitHub Pages | 手機、電腦用同一個網址打開 |
| 資料更新 | GitHub 雲端排程（`.github/workflows/update.yml`） | 台股、美股盤中約每 20–30 分鐘；收盤後各一次完整更新；週末更新新聞 |
| 備援＋歷史 | NAS（`nas/run-backup.sh`） | 用同一套程式獨立產生資料、永久封存每次快照、每日備份 |
| 加速 | 你的電腦 | 自動偵測 `localhost` 的 NPU（8766）、CPU（8767）、語言模型（8768） |

> 這個網站是公開的。持股、成本、論點只存在你自己裝置的瀏覽器裡（可選擇加密備份到你的私密 Gist），不會出現在網站上。

## 第一次設定

1. **開啟網站**：專案 **Settings → Pages → Build and deployment → Source** 選 **GitHub Actions**。
2. **設定 Secrets**（**Settings → Secrets and variables → Actions → New repository secret**）：

| 名稱 | 必要性 | 用途 |
|---|---|---|
| `FINMIND_TOKEN` | 建議 | 台股法人歷史、月營收、籌碼回測、個股新聞 |
| `GEMINI_API_KEY` | 建議 | AI 解讀、全球快報、新聞逐則摘要、題材摘要（aistudio.google.com 免費申請） |
| `NTFY_TOPIC` | 建議 | 手機推播（ntfy App 訂閱同名主題） |
| `BACKUP_GIST_ID`、`BACKUP_PASSPHRASE` | 選用 | 推播時讀取加密備份裡的持股與論點 |
| `FRED_API_KEY` | 選用 | 高收益債利差、金融壓力指數 |
| `ANTHROPIC_API_KEY` | 選用 | 改用 Claude 產生 AI 內容（優先於 Gemini） |
| `TELEGRAM_BOT_TOKEN`、`TELEGRAM_CHAT_ID` | 選用 | 另一個推播管道 |

3. **第一次更新**：**Actions → 更新資料並發布網站 → Run workflow**，「完整更新」填 `all`。約 3–5 分鐘後網站就有資料。
4. 網址：`https://<你的帳號>.github.io/invest-dashboard/`

## 觀察清單

編輯 `config/watchlist.json`（可以直接在 GitHub 網頁上改），存檔後會自動重新產生資料。

| 時間 | 內容 |
|---|---|
| 週一至週五 09:00–13:59 | 台股盤中更新（距上次 20 分鐘以上才跑） |
| 週一至週五 16:40 起 | 台股收盤後完整更新（三大法人、FinMind、AI 解讀、記錄當日訊號），傍晚推播全球快報 |
| 週一至週五 21:00–04:59 | 美股盤中更新 |
| 週二至週六 05:15 起 | 美股收盤後完整更新，早上推播全球快報（不響鈴） |
| 週六、週日每 3 小時 | 新聞、題材與全球快報 |

## NAS 備援

NAS 只負責備援與歷史封存（舊的 invest 主程式可以退役）。在 NAS 上（SSH）執行一次：

```
curl -fsSL https://raw.githubusercontent.com/weichehuang11-cyber/invest-dashboard/main/nas/setup.sh -o /tmp/setup.sh && bash /tmp/setup.sh
```

它會下載程式、安裝套件、第一次完整產生資料，並用 pm2 常駐 `nas/server.js`：在 `http://NAS:8765/backup/` 提供備援網站，並內建排程（盤中每 30 分鐘、台股 16:55、美股 05:45）。不需要再設 DSM 任務排程表。之後要更新程式，再執行一次同一行即可。

產出在 `/volume2/homes/invest-backup/`：`site/`（備援網站）、`archive/snapshots/`（每次快照）、`archive/daily/`、`archive/backup/`（舊 invest 資料每日打包，保留 60 天）。狀態：`http://NAS:8765/backup/status.json`。

### 讓 GitHub 網站能讀到 NAS（Tailscale）

GitHub 網站是 https，只能讀 https 網址的 NAS。

1. DSM **套件中心**安裝 **Tailscale**，登入你的 Tailscale 帳號。
2. 到 Tailscale 管理後台 **DNS**，開啟 **MagicDNS** 與 **HTTPS Certificates**。
3. NAS 上（SSH）執行：`sudo tailscale serve --bg 8765`（找不到指令時改用 `sudo /var/packages/Tailscale/target/bin/tailscale serve --bg 8765`）
4. 網址會是 `https://<NAS 名稱>.<你的 tailnet>.ts.net`。在網站 **設定 → NAS 備援網址** 填入，按「測試連線」。
5. 手機、電腦要安裝 Tailscale App 並登入同一個帳號，才連得到（NAS 不會暴露在公開網路上）。

## 新聞、全球快報與熱門題材

- **全球市場快報**（總覽與「新聞」頁）：只收路透、彭博、CNBC、華爾街日報、金融時報、中央社、經濟日報、工商時報、鉅亨等可信媒體，加上全球 22 項行情（股、債、匯、原物料、比特幣、VIX）。AI 寫成一句話總結、重點、結論與接下來要注意的事；每 3 小時與收盤後更新，早晚各推播一次。
- **重點新聞**：同一事件多家媒體報導的排前面。每則附繁體中文標題、2～3 句摘要、重點條列、投資意義、利多／利空與相關市場；摘要依據會標示「已查證」（AI 用 Google 搜尋查證）、「依內文」或「依標題」。
- **熱門題材**（台股）：`config/themes.json` 的關鍵字＋新聞中自動抓到的「XX概念股／族群／供應鏈」，依新聞量、相關股漲跌排序；AI 說明為什麼熱、目前階段（剛起漲／發酵中／過熱／降溫）與每檔相關個股的看點。
- **個股新聞**：個股頁底部列出近 3 天新聞與所屬題材。

## 市場健康度、事件行事曆、組合分析

- **市場健康度**（總覽）：台股漲跌家數、站上 20／60 日線比例、20 日新高新低（收盤歷史存在 `data` 分支，第一次自動往回補 25 個交易日）；外資台指期未平倉、台指選擇權 P/C 比（期交所）、VIX 期限結構；外資累計與融資餘額；台股本益比中位數、標普本益比與股債利差；美國高收益債利差、金融壓力指數（FRED）。異常會自動列入「今天有什麼變了」與今日判斷。
- **事件行事曆**：FOMC、CPI、非農、央行（`config/events.json`，可自行修改）＋自動推算的台指期結算、美股選擇權到期、月營收截止＋觀察清單財報日。
- **組合分析**（持股頁）：今日損益歸因、對照同配置大盤的績效、波動與最大回撤、組合 Beta、有效持股數、持股相關係數。
- **我的市場感覺**：總覽可每天記錄對台股、美股的感覺（極度恐慌～過熱）；決策紀錄可標註「依據市場感覺」。「我的成績」會統計你的感覺是順勢還是反向指標。

## 個人資料備份與推播通知

- **加密備份與同步**（網站「設定」）：持股（含變動紀錄）、論點（含修改紀錄、已結案）、決策紀錄、市場感覺、自選、提醒，在瀏覽器以密語 AES-256-GCM 加密後存到你 GitHub 帳號的私密 Gist；多台裝置設同一組權杖與密語即自動同步。
- **推播通知**：Secrets 設 `NTFY_TOPIC`（手機 ntfy App 訂閱同名主題）或 `TELEGRAM_BOT_TOKEN`＋`TELEGRAM_CHAT_ID`。再設 `BACKUP_GIST_ID`、`BACKUP_PASSPHRASE`，推播就會檢查你的價格提醒、論點與持股。
- **每週投資週報**：每週一 08:13（`.github/workflows/weekly.yml`），送到相同管道。

## 高信心訊號（5 年回測、時間切分驗證）

每檔每天計算「信心分數」（六項固定條件：技術分數、趨勢、相對大盤強弱、60 日動能、20 日線、RSI；偏多＋1、偏空−1），依分數分組，統計過去 5 年每組之後「5 日贏大盤、20 日贏大盤、20 日上漲」的命中率。前 60% 時間為建立期、後 40% 為驗證期；只有驗證期命中率 ≥ 65%（樣本 ≥ 40）且建立期 ≥ 60% 的分組才標成「高信心」。機會清單可篩選「高信心」，並會推播。回測頁另列期望值（平均獲利、平均虧損、盈虧比、每筆期望值）。

## 策略回測

「系統成績 → 策略回測」（或個股頁「回測這檔」）：用約 2 年日 K，照技術面訊號（與系統相同公式）模擬進出——收盤出訊號、隔天開盤成交、停損停利盤中觸價、扣交易成本。可調買賣門檻、ATR 停損、停利、最長持有、順勢濾網；結果對照一直持有，並檢查前後兩半段是否都穩定。下方另列 AI 模型「訓練日之後」的樣本外表現，避免用訓練過的資料自我評分。

## 財報重點

個股頁「財報重點」：近 8 季營收、毛利率、營益率、EPS 與年增率，近 4 季 EPS、股東權益報酬率、自由現金流、負債比、流動比率；美股另有 EPS 實際 vs 預期、分析師預估修正、PEG、EV/EBITDA。系統自動產生檢查清單與「體質」評等，並納入基本面證據與「我的論點」條件（季營收年減、毛利率下滑、體質轉弱）。台股來源 FinMind（每 5 天更新），美股來源 Yahoo（每天）。

## 指數走勢與推論

總覽的「指數走勢與推論」（加權、標普 500、那斯達克、費城半導體）與每個個股頁的「技術解讀與走勢推論」：

- **技術解讀**：均線排列、季線／年線突破、MACD、KD、RSI、布林通道、量價、支撐壓力，規則化產生中文評論（描述現況）。
- **走勢推論**：波動調整的歷史模擬，給出 5 日與 20 日的中位數、50%／80% 區間，以及「過去相同趨勢狀態下」的上漲機率。
- **可靠度**：每天滾動回測（只用當時以前的資料），顯示 80%／50% 區間實際涵蓋率與方向命中率，並和「單純猜測」基準比較。指數用 10 年日 K。

## 我的論點與成績單

讓這個 dashboard 反映你自己的判斷，而不只是通用訊號（全部只存在你的裝置，不上傳）：

- **我的論點**（個股頁）：寫下理由、目標價、出場條件（跌破價格、虧損超過 %、跌破均線、外資連賣、營收年減、財報前…）。每次資料更新自動檢查，觸發就排在總覽最上面。
- **記錄我的決定**（個股頁）：按「我買了／我賣了／決定不動」，連同理由與當時情境存下來。
- **我的成績單**（底部「我的」）：用之後 1／5／20 個交易日的實際收盤結算，算出你的勝率、是否贏大盤、和系統比較，並找出你的習慣（例如追高、跌破均線買進的平均結果）。
- 持股頁的「匯出／匯入」會一起帶走論點、決策紀錄、自選與提醒。

## 本機加速

Windows 電腦上的本機服務放在 `C:\Users\User\invest_deploy\local-ai`（來源：`invest` 專案）：

1. 雙擊 `switch-to-new.bat`（移除舊版服務並設定開機自動啟動），之後登入 Windows 會在背景啟動 NPU 8766、CPU 8767、語言模型 8768（需 Ollama 與 `qwen2.5:7b`）。
2. 用同一台電腦打開網站，右上角顯示「本機加速：NPU、CPU、語言模型」；**設定 → 檢查本機 NPU／CPU／語言模型**會實際跑一次預測與問答並顯示執行硬體。也可雙擊 `check-local.bat`。
3. 目前 ONNX 模型跑在 Radeon 760M 內顯（DirectML）；XDNA NPU 需另裝 AMD Ryzen AI 軟體，對這個小模型沒有明顯好處。

第一次 Chrome／Edge 可能詢問「是否允許存取區域網路上的裝置」，請按允許。手機或其他電腦打開時會自動略過，改用雲端結果。
